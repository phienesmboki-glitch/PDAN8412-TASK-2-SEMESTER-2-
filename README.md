# Goodreads Bestseller Prediction

## Overview
This project uses Logistic Regression implemented from scratch in Python to predict whether a book is a bestseller proxy based on the Goodreads dataset.

## Files
- `cleaned_goodreads_books_dataset.csv` — dataset used for the analysis.
- `book_bestseller_logistic_regression.ipynb` — commented notebook containing data cleaning, EDA, feature selection, model training, and evaluation.
- `book_bestseller_logistic_regression_report.docx` — detailed written report.
- `book_bestseller_logistic_regression_report.pdf` — PDF version of the report.

## How to Run
1. Install Python and Jupyter Notebook.
2. Install the required libraries: `pandas`, `numpy`, `matplotlib`, and `scikit-learn`.
3. Keep the notebook and CSV dataset in the same folder.
4. Open the notebook and run the cells from top to bottom.

## Important Note
The dataset does not contain verified sales figures. The project uses at least 100,000 Goodreads ratings as a proxy for bestseller status, not as proof of actual sales.
